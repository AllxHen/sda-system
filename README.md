# SDA — Sistema de Agendamento

## Sobre o projeto

O SDA (Sistema de Agendamento) é um projeto de banco de dados desenvolvido com MySQL para praticar modelagem relacional, organização de dados e consultas SQL em um cenário de gerenciamento de agendamentos.

O banco foi estruturado para representar diferentes entidades envolvidas no sistema, como clientes, profissionais, atendentes, serviços, agendamentos, pagamentos e avaliações.

## Tecnologias utilizadas

- MySQL
- SQL

## Estrutura do banco de dados

O projeto contempla entidades relacionadas a:

- Perfis e usuários.
- Clientes.
- Profissionais.
- Atendentes.
- Serviços.
- Agendamentos.
- Estados e status.
- Pagamentos.
- Comprovantes.
- Avaliações.

As tabelas utilizam chaves primárias e relacionamentos por meio de chaves estrangeiras para organizar os dados e estabelecer vínculos entre as entidades.

## Conceitos praticados

- Criação e estruturação de tabelas.
- Modelagem de banco de dados relacional.
- Chaves primárias e estrangeiras.
- Restrições de integridade.
- Inserção e organização de dados de teste.
- Consultas com `SELECT`, `WHERE` e `ORDER BY`.
- Relacionamentos entre tabelas com `INNER JOIN`.
- Agrupamentos com `GROUP BY` e filtros com `HAVING`.
- Funções de agregação, como `COUNT`, `SUM` e `AVG`.
- Procedimentos armazenados (*Stored Procedures*), quando aplicável ao script disponibilizado.

## ▶️ Como executar

**Pré-requisito:** MySQL instalado ou acesso a um ambiente compatível.

1. Clone este repositório:

   ```bash
   git clone https://github.com/AllxHen/sda-system.git
   ```

2. Abra o MySQL Workbench ou outro cliente MySQL.

3. Abra o arquivo SQL principal do repositório.

4. Execute o script para criar a estrutura do banco e inserir os dados de teste.

5. Execute as consultas SQL disponibilizadas para explorar e verificar os dados.

**Importante:** confira o nome do arquivo SQL principal antes de executar o script.

## Objetivo do projeto

Praticar a criação e manipulação de bancos de dados relacionais, desenvolver consultas SQL e compreender como diferentes entidades se relacionam em um sistema de agendamento.

## Observações

Este projeto tem finalidade educacional. Os dados utilizados são destinados a testes e demonstrações.
